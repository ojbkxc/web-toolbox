# web-toolbox — Web 工具箱 (Chrome MV3 扩展)

> 仓库: https://github.com/ojbkxc/web-toolbox (main 分支)

内网自动化的辅助工具箱,零业务逻辑、只产出数据(供 Python 工具链消费)。**目标域名完全可配置**——扩展默认不请求任何域名权限,你在配置页添加哪个域名,它才对哪个域名工作。

**录制 → AI 分析 → 自动关联 → 导出 JMeter/Python → 就地冒烟** 全链路,可替代 BlazeMeter Chrome 扩展且数据不出本机。**全程无需打开 F12。**

> **v0.3 架构**:录制引擎在后台(chrome.debugger),工作台在侧栏(sidepanel)。工具栏 popup 只做极简启动(开始/暂停/停止 + 打开侧栏);查看/过滤/重放/关联/导出/AI 全部在侧栏完成。F12 面板已移除——从安装到压测,整个使用流程不需要 DevTools。

## 🚀 快速上手(5 分钟版,零基础照着点就行)

> 目标:把你在一个网页上的操作(登录→查询→提交…)变成一个能直接运行的 JMeter 压测脚本。全程不用打开 F12。
> 卡住了?每步末尾有"✅ 成功标志"和"💡 常见坑",对照着看。

### 第 1 步:安装扩展(只做一次)

1. 打开 Chrome,地址栏输入 `chrome://extensions` 回车
2. 打开右上角**「开发者模式」**开关(变蓝即开)
3. 点左上角**「加载已解压的扩展程序」**,选中本项目的 `web-toolbox` 文件夹
4. (建议)点浏览器工具栏的拼图图标 🧩 → 给 Web 工具箱点 📌 固定,以后一眼能找到

**✅ 成功标志**:扩展列表出现「Web 工具箱」卡片,浏览器工具栏能看到它的图标。

### 第 2 步:授权你要录制的网站(必做,安全设计)

扩展默认对**任何网站都没有权限**——这是刻意的,不配置就什么都录不到:

1. 点浏览器工具栏的 Web 工具箱图标 → 弹出小窗 → 点 **⚙ 配置域名 / AI 接口**
2. 在「目标域名」输入框填你要测试的网站域名,如 `example.com`(自动授权它的全部子域),点 **「添加并授权」**
3. Chrome 弹出确认框「允许此扩展访问…?」→ 点**「允许」**

**✅ 成功标志**:页面域名列表里出现刚添加的域名。
**💡 常见坑**:录了半天列表是空的?九成是这步没做,或域名拼错(要填域名,不是完整网址,`example.com` 而不是 `https://example.com/xxx`)。建议只配内网测试环境,别配生产。

### 第 3 步:(可选)配置 AI,解锁智能分析

**不配也能用**——录制/重放/导出 JMX 全不依赖 AI;配了才有 AI 报告/错误诊断/参数建链:

1. 还在刚才的配置页,往下滚到「AI 分析接口」
2. 填 API 地址 / 模型 / API Key(走本机代理可不填 Key,直连外部服务才填)
3. 点「测试连通」→ 显示"收到"即配置成功

### 第 4 步:录制你的操作

1. 新开标签页,打开要测试的网站,**正常登录**
2. 点工具栏的 Web 工具箱图标 → 点 **● 开始录制**
3. **像平时一样操作页面**(比如:查一个订单 → 改数量 → 提交),不用管扩展
4. 做完了点扩展图标 → **■ 停止**

**✅ 成功标志**:录制中扩展图标带红色 **REC** 徽章、数字不断上涨;侧栏列表同步新增条目。
**💡 常见坑**:
- 页面顶部出现黄色横条「正在调试此浏览器」→ **正常现象**,这是 Chrome 对调试工具的安全提示,不是中病毒;停止录制即消失
- 想换一个标签页录制?先 **■ 停止**,再对新的标签页点开始(一次只能录一个页面)

### 第 5 步:查看和挑选录制结果

1. 点扩展图标 → **↗ 打开侧栏** → 「录制」页
2. 列表里是抓到的全部请求:方法 / 路径 / 状态码(🟢绿=成功 🟠橙=4xx 🔴红=5xx) / 耗时
3. 点任意一条看详情:请求头/请求体/响应体,还能一键复制 curl 命令
4. 录制里通常混着静态资源和心跳轮询,导出前清一下:
   - 过滤框输入 `POST` 只看写操作、`>=400` 只看失败、`/order` 只看下单链路
   - 或点过滤框旁的 **✂ 清洗** 一键剔除 js/图片/OPTIONS 预检等噪音(删前有明细确认)

**✅ 成功标志**:列表右侧显示「可见 N/总数 M」,你能用过滤词把列表缩到只剩核心业务请求。
**💡 常见坑**:列表空但有请求?侧栏会直接告诉你原因(域名没配 / 请求来自未授权的域 / 录制未附加)。

### 第 6 步:导出 JMeter 脚本并运行

1. 侧栏切到「导出」页 → 点 **JMX** 按钮,下载得到 `webtoolbox_日期.jmx`
2. 智能处理都是自动的,不用手动配:
   - **断言**:每个请求自动挂(HTTP 200 + 从响应推断的业务成功码,如 `$.resultCode=ISC-000`,任何系统通用)
   - **登录**:识别到的登录链自动包进"仅执行一次"控制器,压测循环不会反复登录
   - **动态值**:时间戳/单号等自动参数化,两遍录制的同接口自动 diff 出关联
   - **域名**:统一变量化,换环境(UAT→PROD)改一处即可
3. 本机装了 JMeter(5.x)的话,命令行直接跑:

   ```
   jmeter -Jthreads=10 -Jrampup=10 -Jloops=1 -Jthink=500 -n -t webtoolbox_xxx.jmx
   ```

   (并发线程数/循环次数/思考时间都在命令行调,`-Jthink=0` 关闭思考时间拉满压测)
4. 跑完看 `result.jtl` 或 JMeter GUI 打开 .jmx 看「察看结果树」——失败的请求会标红,点开能看响应体定位原因

**✅ 成功标志**:JMeter 控制台打出汇总(Error 数为 0 即全通过;有 Error 说明接口在压测下真的有问题,点开看是哪个断言失败)。

| **🤖 AI 流量报告** | 侧栏「导出」页 | 已录请求 → LLM 输出业务流程报告:会话概览/流程拆解(登录→查询→提交)/读写接口标注/参数依赖/异常风险 | BlazeMeter 无此功能 |

| **🧪 AI 断言生成** | 侧栏「录制」页 | 为导出集每个接口生成业务断言(状态码/包含/JSON 路径判定),存库后链路重放按断言判成败——状态码 200 但响应含业务错误码(如 ISC-999)也判 ❌;超 30 接口拒绝(先过滤缩集),进度实时显示 | 无 |
| **🤖 AI 技能选择器** | 侧栏「导出」页 | 下拉选技能一键执行:基础 5 个(报告/诊断/建链/文档/断言)+ 高阶 5 个(冒烟解读——自动取最近冒烟统计判瓶颈;契约破坏判定——自动取链路重放 DIFF 快照分噪音/真破坏;接口清单——结构化 Markdown 表;敏感字段扫描——导出前自查泄漏;会话特征回填——找登录/失效特征反哺识别规则) | 无 |
| **⚡ 自动关联** | 侧栏「导出」页 | 同一接口录 2+ 次 → 自动 diff 出动态值(JSON body、`k=v` 表单体、URL query 三形态同管线):时间戳参数化成 `${__time()}`;**单号/UUID 值溯源**——在更早条目的响应里找同值叶子(body 与 query 动态都溯),自动合成参数链挂提取器(重放/JMX/PY 全生效,不再只留一句"建议上游提取") | BlazeMeter 付费云功能,本地离线版 |

| **🔗 AI 参数建链** | 侧栏「导出」页 | LLM 分析可见集,找出跨接口参数传递(响应A.字段 → 请求B.body),生成依赖链;重放/导出 JMX 时自动挂提取器+变量替换 | 无(BlazeMeter 靠手工配 correlator) |
| **▶ 链路重放(回归 diff)** | 侧栏「录制」页底部 | 按顺序重放整条可见集,每条响应 vs 录制快照自动 diff(时间戳/长 token 归一化),出 ✅一致/🟡差异/❌状态码变化/💥错误 汇总——改完代码一键回归整条链 | 无 |

| **♻ 会话失效自动重登** | 侧栏「导出」页开关 | JMX 里生成 IfController 逻辑:首循环登录,响应出现"统一认证"等失效特征时下一循环自动重登,业务链路不丢 | 无 |

| **📋 诊断日志** | 侧栏「导出」页 | 引擎侧环形缓冲(1000 条/512KB 有界,仅元信息不含请求 payload):attach/detach/写入失败/配额裁剪等关键事件,一键导出 JSON 排障;worker 重启即清 | 无 |

## AI 配置(重要)

选项页新增 **"AI 分析接口"** 区:

- **API 地址** / **模型** / **API Key(可空)** 三项完全可配置,任何 OpenAI 兼容端点都行
- 默认 `http://127.0.0.1:8787/v1/chat/completions` + `qwen3.7-plus`——本地代理(LLM 空 Key 直接可用);生产/团队环境在选项页换成你自己的端点
- API Key 可空:本机/自建代理不需要 key,只有直连外部 API 服务时才填;没有 Key 可去 **api.lxseek.com** 购买
- "测试连通"按钮一键验证(发一条"回复:收到")
- ⚠ Key 明文存在 `chrome.storage.local`(本机扩展数据区,与 Cookie 桥导出的 Cookie 同级敏感度;不进同步、不外发)——共用电脑勿配外部 API Key,建议走本地代理转发

- LLM 调用带 **120s 超时**(AbortController)——网关假活/思考模型静默挂起时,UI 不再永远停在"分析中…",超时给出可读错误(等多久、可重试、长流量可先过滤缩小集)

**数据卫生**(发给 LLM 前,扩展侧统一执行,与端点无关):
- Cookie / Authorization 头**永不外发**
- 40+ 字符长 token 值打码为 `前8位***MASKED***`(适用于请求体/响应/请求头/URL query——URL 在源头打码,诊断/断言/冒烟/diff 判定等所有 prompt 一致生效)
- URL query 在条目行呈现时截断到 300 字符(防长 query 挤爆 prompt)
- 请求体截断 1200 字符、响应截断 600 字符(诊断模式放宽到 2000/1500)
- 只有你点"AI 报告/AI 诊断"按钮时才调用 LLM,录制本身零外发

## 域名配置(核心安全设计)

- 添加 `example.com` → 授权 `*.example.com` 全部子域(https+http)
- 添加 `sub.example.com` → 只授权该主机
- 添加 `localhost` / `127.0.0.1` → 精确授权该主机(本地开发联调可用)
- **改配置**: 列表每行有"编辑"按钮 → 行内改域名 → 保存时先申请新授权(Chrome 弹确认框), 通过后才替换清单并撤销旧授权;点"取消"或按 Esc 原样还原
- 配置页会标注覆盖关系:配了 `example.com` 时,列表里它下面的子域配置会显示"被覆盖"(冗余,删掉不影响)
- Cookie 桥会显示当前站点的授权来源(精确授权 / 来自父域 `example.com`),让你知道哪条配置在起作用
- 添加时 Chrome 弹原生权限确认框;删除域名同时撤销授权
- 权限模型:`optional_host_permissions`——**不配置任何域名时,扩展对任何站点都无权工作**
- 所有导出走浏览器下载,不外发任何数据

## 使用

### 导出集 = 勾选优先,否则过滤可见集(所见即所得)
三种圈定方式,优先级从高到低:
1. **☑ 勾选导出集**:过滤框旁点「☐ 勾选」进入勾选模式,列表 checkbox 变为选条目(勾中的标 ●),**全选**按钮一键圈定全部可见集(再点全取消);导出/AI 报告/AI 建链/AI 文档/自动关联/链路重放**只作用于勾选条目**。适合"就要这几条"的精确圈定;再点按钮退出并清空
2. **🔍 过滤词**:空格分词、AND 语义,每词须命中 路径/方法/状态码 之一——`POST` 只看写操作、`500` 只看失败、`>=400` 直接圈出全部失败、`/web/ 500` web 域失败请求、`/order` 下单链路。导出/AI/关联范围 = 可见集
3. 都没用 → 全量 entries

- 过滤与勾选只影响显示与导出,**录制永远全录**,清空过滤框数据就全回来了
- 列表右侧实时显示 `可见 N/总数 M`,导出页顶实时显示当前范围(勾选 N 条 / 可见 N 条)

### ✂ 起点 = 选中条目(裁掉录制开头的噪音)
录制经常从首页导航开始,但业务链路从某条查询才真正开始。在列表**选中那条起点请求**(或详情页点 **`✂ 起点`** 直接跳到导出页开关),导出页出现「从 `GET /web/list` 开始导出」开关(默认开)——四格式导出统一裁掉它之前的条目。录制照常全录,只是导出时掐头。

### ✂ 一键清洗 / 删除勾选
录完一段业务后点过滤框旁的 **`✂ 清洗`**:移除可见集里的 CORS 预检(OPTIONS)、静态资源(js/css/图片/字体)、SSE 流。这些不构成业务接口,留在录制集里只会污染 JMX 和关联分析。清洗前会 confirm 列明细(不可撤销);业务接口(包括 `/xx.json` 形态)不受影响。

想删**指定接口**:点 **`☐ 勾选`** 进入勾选模式,勾上要删的条目,清洗按钮自动变身 **`✂ 删除勾选 N`**,点它即删(删前 confirm 列明细)。全选后删除 = 清空全部;也可以直接用「🗑 丢弃」。

### 🚮 导出自动净化(免清洗的兜底)
不想手动清洗也不会污染脚本:**JMX/PY 导出时自动剔除**预检(OPTIONS)/静态资源/SSE 条目(压测与重放脚本里它们只是采样器噪音),状态栏透明提示剔除了几条;**JSONL/HAR 是数据格式,保真全量不动**。清洗是删源数据(不可逆),净化只影响导出集(可重导)——同一套判定规则,两处生效。

### 列表阅读与单条操作
- **状态码颜色**:2xx 绿 / 4xx 橙 / 5xx 红,失败请求不用扫数字
- **耗时列**:每条显示加载耗时(>1s 黄、>3s 红,阈值与代码常量 SLOW_MS/MID_MS 同源),慢接口一眼可见;详情页也标注
- **单条删除**:详情页 `🗑 删除` 只删这一条(勾选状态/前置标记/AI 链联动清理),不用为一条噪音丢弃整库
- **📋 cURL**:详情页一键复制该请求的 curl 命令(业务头保留、管理头剔除、无 body 不带 -d),贴终端/群里直接跑
- **过滤词状态码语义**:纯数字支持 `>=400`、`>500`、`<300` 比较写法(找失败请求不用数状态码);`POST 500` 等 AND 组合照常

### 🔐 登录前置 + 会话失效自动重登(压测真实形态)
压测脚本不能每轮循环都重新登录,否则压的是登录接口不是业务接口。侧栏自动处理:
1. **自动识别**:录制列表里登录链(CAS/SSO ticket、OAuth token、表单登录、getSetProfile/切换岗位等)自动标 🔐,checkbox 可手动增删(自动识别只认"前缀连续命中",中段误判不会发生)
2. **JMX 导出默认**(前置包仅一次控制器勾选时):登录链进 `OnceOnlyController`(每线程只登录一次) + `TransactionController` 聚合出「登录前置条件」一行(报告里能看到前置耗时),业务链路在外面正常循环
3. **会话失效自动重登**(实验开关):登录链进「未登录则登录」IfController(线程变量 `__logged_in` 控制),业务首采样器挂 JSR223 失效检测——响应含"统一认证/请重新登录"等特征时置 `__logged_in=false`,**下一循环自动重登,业务链路不丢**。适合长压(UAT 会话 30 分钟过期)场景

### Cookie 桥(给 Python 脚本续会话)

2. 点扩展图标 → 「打开侧栏」→ 切到「Cookie」页 → 状态行显示"✓ N 个 Cookie · 域名"(授权来自父域时标注来源;含 httpOnly 的红标 H;可按名搜索找 SSO token,搜不到会提示而不是白屏)

### 请求重放(验证接口)
1. 侧栏「录制」页选中一条请求 → 详情区显示 url/业务头(可编辑)/请求体(可编辑)/响应
2. 改 body 或头 → `▶ 重放` → 响应区显示新结果
3. 等价于在页面 console 手工 fetch,Cookie 永远新鲜,不需要 postman 环境变量

### 自动关联 + 导出 JMeter(BlazeMeter 流程)
1. **把同一业务操作做 2 遍以上**(如建两笔单)——两次录制的同类请求是关联分析的原料
2. 侧栏「导出」页点 **`⚡ 自动关联`** → 列表每条接口标注动态字段:绿色 `timestamp` 已自动换成 `${__time()}`;红色 `seq`(单号/UUID)自动**值溯源**——在更早条目的响应里找同值字段(body 与 query 动态都溯),命中即合成参数链(`🔗⚡` 标,与 AI 建链同构,重放/JMX/PY 全生效);溯源不确定(同值多路径)时保守不链;灰色 `fixed` 保持录制值。JSON body、`k=v&k=v` 表单体、URL query 走同一管线(diff/溯源/替换语义一致)
3. 勾选核心链路条目(把轮询/心跳剔掉),或输过滤词缩范围——关联分析只看导出集
4. 点 **`JMX`** 导出 → 得到 `webtoolbox_时间戳.jmx`,动态替换已应用、Cookie 头已剔除(由 CookieManager 接管)、登录前置包仅一次控制器、每轮循环末尾带 500ms 思考时间
5. 本地跑: `jmeter -Jthreads=10 -Jrampup=10 -Jloops=1 -Jthink=500 -n -t webtoolbox_xxx.jmx`(`-Jthink=0` 关闭思考时间拉满压测)

### 就地冒烟(快速定性验证)
1. 侧栏选中一条请求 → 点 **`🔥 冒烟`** → 设并发(1~20)与总次数
2. 等待完成 → P50/P90/P95/P99/MAX/吞吐 req/s/错误率
3. 适合"这个接口能不能扛住 10 并发"的快速判断;浏览器页面上下文的限制决定了数字偏保守(同域连接池排队、单用户会话),**不要拿它当性能基准**;严肃压测(百并发/分布式/断言)导 JMX

### AI 流量报告(交接/写文档神器)

### 🔗 AI 参数建链(自动联调)
1. 录一段带依赖的业务(如查询出单号 → 详情页用单号)
2. 点 **`🔗 AI 参数建链`** → LLM 分析跨接口参数传递,输出依赖链:`[查询接口].resp.$.orderId → [详情接口].body.orderNo`
3. 链存进 `toolbox.aiChain`,重放/链路重放/JMX 导出时自动应用(JSON 提取器 + 变量替换)——录制里依赖 A 响应的请求,重放时自动取 A 的最新响应
4. **注入范围**:目标参数三种形态都支持——`body.字段`(JSON 体和 `k=v&k=v` 表单体)、`header.头名`、`url.参数名`(query 参数与 REST 路径段 `/order/id/123` 都认);来源路径支持数组下标(`data.list.0.id`),多级链(登录→查询→详情)上游值全程存活
5. **链对用户可见**:已建链再点「🔗 建链」是查看器——每条链的来源接口/提取路径/注入目标/变量名一目了然,可 📋 复制 JSON 或 🗑 清除重建;链路重放汇总里附**注入回执**(`✅ v1 → body.orderNo` 生效了哪些 / `⚠ 没取到值` 哪些没生效),出差异先看回执分清"链没生效"还是"接口真变了"
6. **JMX 联动**:导出 JMX 时自动把链转成 JSONPath 提取器(`$.data.orderNo`)+ `${var}` 参数化,与重放注入同语义;popup 一键导出同样生效
7. **PY 联动**:导出 PY 脚本同样应用链——上游步骤响应自动提取(内置 `pick()` 路径取值,取不到时明示"下游用录制值")、下游步骤参数自动替换(body JSON/表单/query/路径段/header 全形态),`ctx` 变量池跨步骤共享,换会话换单号脚本不再 404

## 技术说明

- **录制引擎为什么在后台**:MV3 `webRequest` 拿不到响应体;`chrome.debugger`(Network domain)能拿全量请求+响应且**不需要 F12**——BlazeMeter 扩展同款机制。代价:录制时页面顶部有"正在调试"黄条(Chrome 安全设计,不可去除),停止即消失。
- **重放为什么在页面上下文**:`chrome.scripting.executeScript` 注入 MAIN world,浏览器自动附当前 Cookie(含 httpOnly),会话永远是新鲜的——这从机制上消灭"Cookie 文件过期/漏 token"。
- **service worker 常活设计**:录制期间 `chrome.alarms` 保活(周期唤醒重置 MV3 30s idle 计时),事件零丢失;worker 被回收后唤醒即从 storage 重载状态,徽章/过滤条件即时恢复。
- **UI 状态推送替代轮询**:popup/侧栏打开时主动拉一次,之后靠 `storage.onChanged` 推送(录制态/条数实时同步)——popup 常开时不再每秒唤醒 worker,侧栏常驻时 worker 可正常休眠。
- **录制状态徽章**:录制中扩展图标显示红色 REC、暂停显示橙色 ‖——popup/侧栏全关也能一眼看到录制状态。
- 录制上限 3000 条/会话,存 `chrome.storage.local`(带版本信封 `{v, entries}` 格式),popup/侧栏关掉不丢、浏览器重启前都在。
- **配额治理**:`chrome.storage.local` 有 10MB 上限(超后写入抛错丢数据)。录制库按配额 75% 预算自动裁最旧条目(最新一条永远保留),写入前合帧(同 tick 攒批一次写);数据损坏时自动备份到 `toolbox.harvest.corrupt` 再重建,不静默丢——popup 也会明示"数据损坏, 已隔离"而非裸 0 条(防止误读成"没录上"重录覆盖)。
- **暂停语义**:点 ⏸ 暂停后新请求不再入列,但暂停前已在飞的在途请求照常落库(不丢半截响应)——点 ▶ 继续走新会话语义。
- **链路重放的逐条容错**:页面注入(executeScript)被 CSP 拦截或页面未授权时,该条标 ERR 并保留原始错误,**链路继续不中断**——一条挂不拖死整条链。
- 若目标页面已被其他调试工具(如抓包软件)占用调试端口,开始录制会失败并提示——关掉占用工具再开始。

## 已知边界

- 重放器不重放录制快照里的 `Authorization`/`Cookie` 头(前者是过期凭据、避免误带别处 token,后者由浏览器自动管理)——**AI 参数链显式注入的 `header.*` 头除外**(如 Bearer 建链注入的 Authorization 是前序响应提取的 live 值,不随快照剔除;JMX/PY 导出同语义)
- 响应体是录制时的快照,base64/二进制内容显示为略
- 录制引擎与页面一一对应:一次录一个标签页(换标签页录制,先停止再对新的开始)
- 勾选模式清空全部勾选后退回过滤可见集(按钮显示"已选 0"但导出/关联/AI 仍作用可见集)——空勾选集不是"导出空集";想导空集请先清录制数据
- 勾选模式下起点裁剪在勾选集内找选中条目:起点不在勾选集时不裁剪(导出页有"该起点不在勾选集内"提示,不是静默)
- 勾选集随侧栏持久(toolbox.pickIds):重开侧栏自动恢复勾选模式与勾选;被删/被裁条目的勾选自动失效,不残留死计数
- 删除/清洗掉当前选中条时自动就近补选相邻条(详情区不退空态);有数据未选中时详情区显示录制摘要(总数/失败/慢)
- Cookie 页父域上溯对 `co.uk` 类双段 TLD 会近似查一次公共后缀域(如 `foo.co.uk` 页面查 `co.uk` 的 Cookie)——多一次查询但零误报(公共后缀无人能注册,查不到东西)
